기흥푸르지오포레피스 인사평가 업데이트

반영 내용
1. 관리소장 전용페이지에 '관리소장 2차 평가' 입력/제출 기능을 명확히 표시
2. 관리자 평가단계가 first 또는 second인 경우 관리소장 평가 저장 가능
3. 제출한 직원은 기본적으로 수정 불가
4. 관리자 '직원 · 계정' 메뉴에서 본인평가/동료평가 재작성 허용 가능
5. 관리자가 허용한 경우에만 직원이 다시 수정 가능
6. 직원이 다시 제출하는 순간 재작성 권한 자동 잠금
7. 다시 수정하려면 관리자가 다시 '수정 허용'해야 함
8. 직원 접속기간 제한은 기존대로 유지

적용 순서
A. Supabase SQL Editor에서 카톡전송용_평가재작성권한_업데이트_SQL.txt 실행
B. 서버 Control+C
C. 프로젝트 폴더에서 패치 ZIP을 unzip -o 로 병합
D. rm -rf .next
E. npm run dev -- -p 3001
