[직원 계정 삭제 기능 패치]

1) 인사평가 서버 종료: Control + C
2) 현재 프로젝트 폴더로 이동
   cd ~/Downloads/"forepice-hr-evaluation 2"
3) 패치 적용
   unzip -o ~/Downloads/forepiece-hr-employee-delete-patch.zip -d .
4) 캐시 삭제
   rm -rf .next
5) 다시 실행
   npm run dev -- -p 3001
6) 관리자페이지 → 직원 · ID → 직원 계정 목록에서 '삭제' 버튼 확인

※ 평가자료가 없는 계정: 1차 확인 후 바로 삭제
※ 평가자료가 있는 계정: 관련 자료 건수 표시 후 2차 확인
※ 최종 삭제 시 해당 직원의 본인평가, 평가자/평가대상으로 연결된 동료평가, 직원전용 평가항목도 DB 외래키 규칙에 따라 함께 삭제됩니다.
※ /manager 관리소장 전용 로그인 계정은 직원 계정과 별도이므로 이 삭제 기능의 영향을 받지 않습니다.
