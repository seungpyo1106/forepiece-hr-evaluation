# 기흥 푸르지오 포레피스 관리사무소 인사평가

가을캠핑 페이지와 같은 **Next.js + Supabase + Vercel** 구조의 인사평가 웹앱입니다.

## 구현 기능
- 직원별 개별 ID/PW 로그인
- 관리자 설정 평가기간 외 로그인 차단: `평가기간이 종료 되었습니다.`
- 동료평가: 본인 제외 전 직원, 대상자별 화면 분리, 임시저장, 최종제출, 제출 후 잠금
- 동료평가 비공개/참고자료 고지
- 자기 인사평가: 30/20/20/15/15점 = 100점, 임시저장, 최종제출, 제출 후 잠금
- 자동 등급: S 95+, A 85~94, B 75~84, C 65~74, D 65 미만
- 자동 인상률: S 3%, A 2.5%, B 2%, C 1.5%, D 0%
- 관리자: 진행현황, 등급 인원, 직원 계정 랜덤 생성/재생성, 평가항목 직원별/공통 설정, 기간/안내문구, 결과 열람
- 관리소장 전용 `/manager` 로그인/대시보드: 직원별 최종 본인평가 열람 + 익명 동료평가 종합
- 관리소장 동료평가 보호: 평가자 정보 미전송, 항목별 3명 미만 응답 자동 비공개
- 관리자에서 관리소장 전용 ID/PW 생성·변경
- Excel(.xlsx) / Word(.docx) 다운로드

## 1. Supabase
1. 새 Supabase 프로젝트 생성
2. SQL Editor에서 `supabase.sql` 전체 실행
3. Project Settings > API에서 URL과 `service_role` key 확인

## 2. 로컬 실행
```bash
cp .env.example .env.local
npm install
npm run dev
```
브라우저:
- 직원: http://localhost:3000
- 관리소장: http://localhost:3000/manager
- 관리자: http://localhost:3000/admin

`.env.local` 예시:
```env
APP_SECRET=충분히-긴-랜덤-문자열
ADMIN_PASSWORD=관리자비밀번호
SUPABASE_URL=https://xxxxx.supabase.co
SUPABASE_SERVICE_ROLE_KEY=xxxxx
```

> `SUPABASE_SERVICE_ROLE_KEY`는 서버 전용입니다. 브라우저 코드나 GitHub 공개 저장소에 절대 넣지 마세요.

## 3. Vercel 배포
1. 이 폴더를 GitHub 저장소에 업로드
2. Vercel > Add New > Project > GitHub 저장소 Import
3. Settings > Environment Variables에 `.env.local`의 4개 값을 동일하게 등록
4. Deploy

## 관리자 사용 순서
1. `/admin` 로그인
2. `기간/안내`에서 2026년 평가 시작/종료일과 메인 문구 설정
3. `직원/ID`에서 직원 등록 → 랜덤 ID/PW 전달
4. `관리소장`에서 관리소장 전용 계정 생성 또는 랜덤 ID/PW 발급
5. `평가항목`에서 공통 또는 특정 직원에게만 보이는 동료평가/인사평가 문항 설정
6. 평가기간 중 `현황`에서 제출상태 확인
7. 관리소장은 `/manager`에서 직원별 최종 자기평가 및 익명 동료평가 종합 확인
8. 종료 후 `결과/다운로드`에서 Word/Excel 저장

## 중요: 등급 인원 기준
점수에 따라 자동 등급을 계산합니다. 동시에 관리자 대시보드에서 다음 권장 인원을 표시합니다.
- S: 0~1명
- A: 1~2명
- B: 4~5명
- C: 1~2명
- D: 동결

자동 점수등급과 권장 인원은 서로 충돌할 수 있으므로, 현재 버전은 **점수등급을 자동 계산하고 권장 인원은 관리자 참고값으로 표시**합니다.


## 관리소장 화면의 개인정보/익명성 기준
- 관리소장 API에는 동료평가자의 이름·ID를 전달하지 않습니다.
- 본인 인사평가는 직원이 최종 제출한 이후에만 상세내용이 공개됩니다. 임시저장 중에는 `작성중` 상태만 표시됩니다.
- 동료평가는 평가대상 직원 기준으로 참여 인원, 점수형 항목 평균, 서술형 익명 의견을 묶어 표시합니다.
- 동일 항목에 응답이 3건 미만이면 익명성 보호를 위해 평균과 의견을 표시하지 않습니다.
- 관리소장 페이지는 읽기 전용이며 평가항목/계정/점수/기간을 수정할 수 없습니다.

## 기존 DB에 관리소장 기능만 추가하는 경우
이미 이전 `supabase.sql`을 실행했다면 `supabase-manager-update.sql`만 SQL Editor에서 추가 실행해도 됩니다. 새로 시작하는 경우에는 최신 `supabase.sql`만 실행하면 됩니다.
